## Grade Calculation Guide

This application helps students
calculate their academic results.

### Calculation Information

- Subject marks
- Total marks
- Average percentage
- Grade estimation

### How to Use

1. Enter the obtained marks.
2. Provide the maximum marks.
3. Calculate the result.
4. Review the displayed grade.

### Important Notes

Grading systems may vary between
educational institutions.

Always use the grading scale
specified by the relevant institution.
## Manual Testing Checklist

- [ ] Calculate results using a simple known marks example.
- [ ] Check the result at a grade boundary.
- [ ] Reject values beyond the permitted marks range.

Record the observed result and any reproducible issue after running the tests.
